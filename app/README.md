# Zenvora app

This folder holds the Zenvora source: the React UI (`src/`), the Electron desktop shell (`electron/`) and the packaging setup.

Setup, configuration, API integration, hosting and release instructions are in the [main README](../README.md).

```bash
npm install
npm run dev        # web preview at http://localhost:5173
npm run electron   # desktop app
npm test           # unit tests
```
